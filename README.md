# About cdproto

Package `cdproto` contains the generated commands, types, and events for the
[Chrome DevTools Protocol domains][devtools-protocol].

[![Unit Tests][cdproto-ci-status]][cdproto-ci]
[![Go Reference][goref-cdproto-status]][goref-cdproto]

This package is generated by the [`pdlgen`][pdlgen] command. Please refer to
that project and to the main [`chromedp`][chromedp] project for information on
using the commands, types, and events available here.

## Install

```sh
go get github.com/chromedp/cdproto@latest
```

The package needs Go 1.27 or later, because the generated code uses
`encoding/json/v2` from the standard library.

## Using the API

Each protocol command is a value with a parameter type and a result type. The
function `cdp.Call` runs it on a session. Each protocol event is a value too.
The function `cdp.Events` returns an iterator for it.

```go
res, err := cdp.Call(ctx, session, page.Navigate, page.NavigateParams{URL: "https://example.com"})
```

See the [Go Reference][goref-cdproto] for the API, and `docs/API.md` in the
[`pdlgen`][pdlgen] project for the rules that the generator follows.

## Versions

A tag has the form `v0.<major>.<patch>`, where the minor version is the
Chromium major version of the protocol. Any release can contain incompatible
changes, because the protocol removes and renames things. `CHANGELOG.md` and the
annotation of each tag list the changes. The releases up to `v0.157.2` have the
old API, which had a `Do` method on each command. The first release after
`v0.157.2` has the typed API.
